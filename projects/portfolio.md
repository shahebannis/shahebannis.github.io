# Portfolio Website

This portfolio website is a modern, responsive showcase of my work, skills, and professional journey. Built with HTML, CSS (Tailwind), and JavaScript, it serves as a central hub for my projects, blog posts, and contact information.

## Features

- **Responsive Design:** Optimized for all devices, ensuring a seamless experience on desktop, tablet, and mobile.
- **Dark Mode:** Toggle between light and dark themes for comfortable viewing in any environment.
- **Animated Background:** Subtle particle animations add a dynamic and engaging visual touch.
- **Project Showcase:** Curated list of selected projects, each with detailed descriptions and links to source code or further information.
- **Markdown Integration:** Project details are written in Markdown for easy editing and rich formatting.
- **Modal Project Viewer:** Clicking "Learn More" on a project opens a fullscreen modal with a comprehensive project overview.
- **Private Project Support:** Ability to highlight private projects with badges and custom notes.
- **Navigation Bar:** Quick access to About, Projects, Blogs, and Contact sections.
- **Contact Links:** Direct links to LinkedIn, GitHub, and email for professional networking and inquiries.
- **Blog Integration:** Space for sharing technical articles, tutorials, and personal insights.

## Technologies Used

- **HTML5 & CSS3**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Font Awesome**
- **Marked.js (for Markdown rendering)**

## Purpose

The portfolio is designed to present my work in a clear, organized, and visually appealing manner, making it easy for potential collaborators, employers, and clients to explore my skills and achievements. It reflects my commitment to clean design, usability, and modern web development
