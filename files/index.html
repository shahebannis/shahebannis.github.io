Research

MSc Thesis  ·  Concordia  ·  in progress

Low latency Volumetric Multimedia Streaming

Im researching dynamic point cloud compression for immersive 3D media, focussing on the effect of compression on the perceived quality of the final output. The project evaluates the codec's outputs using both objective metrics and subjective user studies. Its goal is to build a fair evaluation framework for understanding how to optimize point cloud video for real-time streaming.
